# Repository screenshot record

These screenshots show the rendered interface. The v1.3.0 captures were made
in Chrome on 26 July 2026 from a clean local origin. The two-tool annotation
captures were refreshed on 27 July 2026 after the source-faithful showcase was
added. Desktop captures used a 1440 by 900 viewport. The mobile capture used a
390 by 844 viewport.

The original v1.3.0 interface captures used dark mode and the default empty
project. The annotation captures use the light tutorial shell around each
tool's authentic light or dark interface. They contain only the first three
permitted frame-annotator examples and public, non-in-vivo LASK v1.0 frames.
No patient data, private research material, credentials, or external browser
chrome appear. The screenshots are project documentation and are covered by
the repository's CC BY 4.0 content licence, with LASK attribution retained
under CC BY 4.0.
