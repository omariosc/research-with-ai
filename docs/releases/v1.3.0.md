# Research with AI v1.3.0

This release adds project-scoped workspaces and three substantial evidence
deep dives to the Research with AI tutorial platform.

## Highlights

- Named local projects with separate notes, progress, assessments, deep-dive
  checks, and builder drafts.
- An original comparison of Google Co-Scientist, AI Scientist v1 and v2, the
  related Nature study, and Medical AI Scientist.
- A first-hand annotation-tool account linked to public frame-annotator commits
  and LASK v1.0, with recollection kept separate from public evidence.
- An original synthetic annotation scene with no patient or clinical image.
- A complete synthetic FastAPI and Docker teaching pack with locked
  dependencies, negative tests, least-privilege controls, Raspberry Pi and
  Jetson guidance, and a deployment record.
- Annotation specification schema 1.3.0.

## Validation

The reviewed release passed:

- production build, lint, type checking, and 53 release tests;
- annotation round-trip and BreastMNIST evidence checks;
- locked Python and live Docker acceptance checks;
- dependency and external-link audits;
- desktop and mobile Chrome review in light and dark modes; and
- the below-4,000-word tutorial limit excluding references.

The
[release evidence record](../../public/audits/platform-release-v1.3.0-2026-07-26.md)
contains the exact claims, rights decisions, word counts, checks, and remaining
human gates.
