# AI use disclosure

ChatGPT and Codex assisted with source discovery, information architecture,
drafting, implementation, repository inspection, and interface testing for
this project. An OpenAI image-generation model produced the social preview
image. The tutorial also discusses Claude and Claude Science using linked
first-party documentation, but that coverage should not be read as an
endorsement or as evidence that every product was used to build the site.

AI output was treated as a proposal, not as evidence. Sources were linked for
reader verification, generated code was tested locally, and the final
scientific, ethical, and editorial decisions remain the author's
responsibility.

No patient data, private research records, credentials, or identifiable study
material were intentionally supplied during development. The annotation demo
uses a screenshot from the author's public `frame-annotator` repository and is
labelled as a teaching example rather than a clinical system.

Before submission or public reuse, the author should complete a final
line-by-line review of claims, citations, licences, accessibility, and the
recorded examples.
